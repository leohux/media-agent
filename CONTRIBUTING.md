This is **media-agent**, a personal project by [Leo Hu](https://github.com/leohux).

- Site extractor bugs and new sites: report them upstream at [yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp), unless the bug is in the agent wrapper.
