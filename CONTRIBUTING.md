# Contributing

This is a personal agent project by [Leo Hu](https://github.com/leohux), built on [yt-dlp](https://github.com/yt-dlp/yt-dlp).

- Agent / MCP changes: open an issue or PR in **this** repository.
- Site extractor bugs and new sites: please report them upstream at [yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp), unless the bug is in the agent wrapper.
